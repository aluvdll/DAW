# DAW
Este repositorio recopila los ejercicios y prácticas de la asignatura Despliegue de Aplicaciones Web, impartida por Raquel Esteve Sanjuan en el segundo curso del ciclo de Desarrollo de Aplicaciones Web (DAW) en modalidad semipresencial del IES Pere Maria Orts i Bosch.

## Contenido

Este repositorio incluye:

Ejercicios prácticos relacionados con el despliegue de aplicaciones web.

Código fuente y configuraciones necesarias para las tareas asignadas.

Documentación de apoyo y guías.

Uso del Repositorio

Clonar el repositorio:

git clone https://github.com/tu-usuario/tu-repositorio.git

Navegar por las carpetas para encontrar los ejercicios o prácticas deseados.

Seguir las instrucciones específicas en cada archivo para ejecutar el contenido correctamente.
